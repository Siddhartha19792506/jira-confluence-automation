# Project Specification

## Project Overview
Build a simple Python calculator module and demo script for basic arithmetic operations.

## Functional Requirements
- Provide arithmetic operations for addition, subtraction, multiplication, and division.
- Expose calculator operations through a class-based API named `Calculator`.
- Include the following methods:
  - `Calculator.add(a, b)`
  - `Calculator.subtract(a, b)`
  - `Calculator.multiply(a, b)`
  - `Calculator.divide(a, b)`
- Include a runnable demo script that shows example usage and prints results.

## Technical Requirements
- Language: Python 3.x
- Keep logic in `work/module03-task/calculator.py`.
- Keep the demo entry point in `work/module03-task/main.py`.
- Repository should use Git for version tracking.

## Scope
- In scope: basic arithmetic operations and CLI demonstration through printed output.
- Out of scope: GUI, web API, persistent storage, and advanced math functions.

## Acceptance Criteria
- Running the demo script prints valid arithmetic results.
- `Calculator` class methods return correct values for representative numeric inputs.
- Project files are committed to Git with clear commit messages.
