# Weekly Status Report Agent Instructions

Generate a weekly status report using Markdown.

Requirements:
- Use bullet points only.
- Keep the report to a maximum of 20 lines total.
- Maintain a professional tone.
- Avoid fluff words and vague filler language.

Required sections:
- Accomplishments
- Blockers
- Next Week

Output rules:
- Include only the three required sections.
- Use concise, specific statements.
- Do not include paragraphs, tables, or code blocks.
